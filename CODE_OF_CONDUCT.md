# Verhaltenskodex

fw-ams soll ein freundlicher Ort für alle sein – unabhängig von Erfahrung, Herkunft, Geschlecht,
Identität, Alter, Behinderung, Aussehen, Religion oder Weltanschauung.

Für dieses Projekt gilt der
[Contributor Covenant, Version 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).

Kurz gesagt:

- Respektvoll und geduldig miteinander umgehen, auch bei Meinungsverschiedenheiten.
- Konstruktive Kritik an Code und Ideen üben, nicht an Personen.
- Keine Beleidigungen, Belästigung, Diskriminierung oder Veröffentlichung privater Daten anderer.

Verstöße bitte vertraulich an den Maintainer melden, über
[Security → Report a vulnerability](https://github.com/M-0-K/fw-ams/security/advisories/new)
mit dem Hinweis „Verhaltenskodex“ oder per Nachricht an [@M-0-K](https://github.com/M-0-K).
Jede Meldung wird vertraulich behandelt.
